# Gestionale Laboratorio Orafo

Gestionale per laboratorio orafo in HTML, CSS e JavaScript puri: nessuna installazione, nessuna build.

## Uso
Apri `index.html` nel browser (doppio clic). Su GitHub puoi pubblicarlo gratis con **Settings → Pages → Deploy from a branch → main / root**.

## Dati
Clienti, schede e impostazioni sono salvati nel `localStorage` del browser (restano sul dispositivo in uso). Da **Impostazioni** puoi esportare/importare un backup JSON.
